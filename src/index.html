设置


主题风格
主题存在本机，下次打开 OpenLoc 还是你选的那个。黑色主题是纯黑背景、深灰卡片、青色按钮。


模型存放
模型默认存在程序旁的 data/models/。已下载的模型不会自动搬家。


界面语言
界面目前只有简体中文，选 English 暂不翻译，下一版再做英文界面。

推理引擎
安装和启动在「运行」页。聊天引擎来自 llama.cpp，画图和视频引擎来自 stable-diffusion.cpp，源码在 GitHub，许可证是 MIT。








本地 API 端口
聊天服务默认跑在 127.0.0.1:8080，只限本机访问，不对外网开放。改完端口，下次启动聊天服务时生效。


授权控制
OpenLoc 只能控制下面这些它自己的后台程序，不碰你电脑上的其他程序。哪项没勾，OpenLoc 就不会做那件事。

关于

OpenLoc 把引擎当作自己的能力来安装和启动：聊天是 llama.cpp 的 llama-server，画图和扩散视频是 stable-diffusion.cpp 的 sd-cli。两份都是 GitHub 上的公开项目，许可证为 MIT。模型权重在 Hugging Face，不随安装包附带。


聊天引擎 https://github.com/ggml-org/llama.cpp （MIT）


画图 / 视频引擎 https://github.com/leejet/stable-diffusion.cpp （MIT）


对话模型 https://huggingface.co/unsloth


Wan 视频模型 https://github.com/Wan-Video/Wan2.2 ，权重在 Hugging Face 的 Wan-AI


致谢上述开源项目。




关于加速
OpenLoc 不做付费加速通道，所有引擎和模型都直接从 GitHub / HuggingFace 免费下载，下载速度取决于你的网络。
