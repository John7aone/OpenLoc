已经有模型文件？

选择 .gguf / .safetensors / .ckpt 导入到 data/models。分卷文件选第一卷即可；同目录的 mmproj 会当作看图组件。浏览器往往只给文件名、不给完整路径，那种情况不会假装已经导入。

每个画图 / 视频模型包含主体、文本编码器和 VAE，点下载会按你选的量化去找整套文件（桌面版才会真的拉）。体积写的是约数，以官方仓库为准。已经在别处下好了？导入本地文件。

画图模型

点开仓库后，每个文件在下载按钮旁边显示体积、近 30 天仓库下载次数，以及本机 tok/s。体积是仓库文件的字节。下载次数是整个仓库的，不是单个文件。tok/s 标成「估算」，和推荐模型用同一套带宽公式，不是跑分。没有读到显卡和内存时不编速度。

输入模型名字搜索 HuggingFace 上的 GGUF 模型，例如 qwen3.8、gemma-4、glm

方式一：动效视频（ffmpeg）——把一张图做成推近动效，这是动效，不是扩散生成，CPU 就能跑。




方式二：扩散视频（Wan）——调用 sd-cli 的 vid_gen，需要 Wan 视频模型和足够显存，没有会直接报错，不会给你假视频。

本地创作工坊。模型、对话和作品留在本机。














这一版不连接更新服务器。要看有没有新版本，请到项目仓库。





高级设置


HuggingFace 令牌（可选）


下载需要同意协议的模型时才发给 huggingface.co，或你在下面填写的镜像。不回显。留空再保存会保留已有令牌；输入一个减号再保存会清掉。





HuggingFace 镜像（可选）


把 huggingface.co 换成这个 https 根地址。留空就走官方。只用于免费公开下载。





GitHub 下载前缀（可选）


从 GitHub 下载引擎时加在公开地址前面。留空就直接访问 GitHub。这不是付费线路。




OpenLoc 没有付费加速，也没有单独的高速下载线路。引擎和模型只从 GitHub、Hugging Face，或你自己填的 https 镜像下载。






授权控制


OpenLoc 只控制它自己的后台程序。哪项没勾，就不会做那件事。






授权存在本机，下次打开 OpenLoc 还在。


后台程序




点刷新，看 OpenLoc 现在在后台跑着哪些程序。网页预览没有这些进程。








第三方 API













Key 只写在这台电脑上。编辑时留空会保留原来的 Key。












Key 只写在这台电脑的本地存储里，设置页不回显，也不会从这里发出去。对话和 Agent 目前只走本机 llama.cpp，顶部还不能改用这些接口。












推理引擎是 llama.cpp 和 stable-diffusion.cpp（MIT）。模型和对话都保存在你的电脑上，不会上传。OpenLoc 不设账号，也不做付费加速。项目页 github.com/John7aone/OpenLoc
