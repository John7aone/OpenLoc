检测不到显卡，或者显存不对？
目前只认自动检测到的 NVIDIA 显卡。检测不到时，运行页走 CPU / 内存，不会假装有一块显卡。




推理引擎


安装和启动在运行页。聊天引擎来自 llama.cpp，画图和视频引擎来自 stable-diffusion.cpp，源码在 GitHub，许可证是 MIT。








有 NVIDIA 显卡用 CUDA 版，否则把地址换成 CPU 版再下。网页预览点下载只会说明做不到。




本地 API 端口




聊天服务默认跑在 127.0.0.1:8080，只限本机。被占用时请改一个空闲端口，下次启动生效。不会自动对外网开放。




关于 OpenLoc


OpenLoc 是跑在你电脑上的本地创作工坊。模型、对话和 Agent 的文件都留在本机。聊天引擎是 llama.cpp，画图和扩散视频是 stable-diffusion.cpp，许可证都是 MIT。模型权重在 Hugging Face，不随安装包附带。




这一版不连接更新服务器。要看有没有新版本，请到项目仓库。浅色是灰白底，深色是海军蓝底，主色是蓝。




授权控制


OpenLoc 只能控制下面这些它自己的后台程序，不碰你电脑上的其他程序。哪项没勾，就不会做那件事。






授权存在本机，下次打开 OpenLoc 还在。


后台程序
点刷新，看 OpenLoc 现在在后台跑着哪些程序。网页预览没有这些进程。


关于加速


不做付费加速。 OpenLoc 没有付费加速通道。引擎和模型都从 GitHub / Hugging Face 免费下载，速度取决于你自己的网络。
