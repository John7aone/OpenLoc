安全边界：Agent 只能在你指定的工作文件夹里读写文件、跑命令，超出文件夹、含 ..、删除、格式化等一律拦截。不要把整个文档、桌面或系统盘交给它。Agent 要用聊天服务里的本地模型做计划，先在对话页启动服务；小模型做计划可能不稳定，大模型效果更好。




画图


需要先下载画图引擎和一个 SD 模型（.safetensors 也可以导入）。没有 GPU 会很慢，这是实话。








视频


方式一：动效视频（ffmpeg）——把一张图做成推近动效，这是动效，不是扩散生成，CPU 就能跑。




方式二：扩散视频（Wan）——调用 sd-cli 的 vid_gen，需要 Wan 视频模型和足够显存，没有会直接报错，不会给你假视频。







设置


主题风格
主题存在本机，下次打开 OpenLoc 还是你选的那个。黑色主题是纯黑背景、深灰卡片、青色按钮。


模型存放
模型默认存在程序旁的 data/models/。已下载的模型不会自动搬家。


界面语言
界面目前只有简体中文，选 English 暂不翻译，下一版再做英文界面。

检测中…


推理引擎
引擎不在安装包里，第一次用时点下载：llama.cpp（聊天）、stable-diffusion.cpp（画图/视频）都是 GitHub 开源项目，免费下载。








本地 API 端口
聊天服务默认跑在 127.0.0.1:8080，只限本机访问，不对外网开放。改完端口，下次启动聊天服务时生效。


授权控制
OpenLoc 只能控制下面这些它自己的后台程序，不碰你电脑上的其他程序。哪项没勾，OpenLoc 就不会做那件事。






授权存在本机，下次打开 OpenLoc 还在。


后台程序
点刷新，看 OpenLoc 现在在后台跑着哪些程序。


关于加速
OpenLoc 不做付费加速通道，所有引擎和模型都直接从 GitHub / HuggingFace 免费下载，下载速度取决于你的网络。
